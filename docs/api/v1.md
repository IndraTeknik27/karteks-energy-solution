## 1. Authentication

All authenticated endpoints require a Sanctum token:
```
Authorization: Bearer {token}
```

### 1.1 Register
```
POST /auth/register
Content-Type: application/json

{
    "name": "Budi Santoso",
    "email": "budi@example.com",
    "phone": "6281234567890",
    "password": "Password123!",
    "password_confirmation": "Password123!"
}
```

**Response 201:**
```json
{
    "success": true,
    "message": "Registrasi berhasil. Silakan verifikasi email Anda.",
    "data": {
        "user": {
            "id": 2,
            "name": "Budi Santoso",
            "email": "budi@example.com",
            "phone": "6281234567890",
            "email_verified_at": null
        },
        "token": "1|abc123...",
        "token_type": "Bearer"
    }
}
```

### 1.2 Login
```
POST /auth/login
Content-Type: application/json

{
    "email": "budi@example.com",
    "password": "Password123!"
}
```

**Response 200:**
```json
{
    "success": true,
    "message": "Login berhasil.",
    "data": {
        "user": { "id": 2, "name": "Budi Santoso", "email": "budi@example.com", ... },
        "token": "2|xyz789...",
        "token_type": "Bearer"
    }
}
```

**Error 422 (Brute force / validation):**
```json
{
    "success": false,
    "message": "Email atau password salah.",
    "error": "auth_invalid_credentials"
}
```

**Error 429 (Rate limited — 5 failed attempts/15 min):**
```json
{
    "success": false,
    "message": "Terlalu banyak percobaan login. Silakan coba lagi dalam beberapa menit.",
    "error": "auth_rate_limit"
}
```

### 1.3 Logout
```
POST /auth/logout
Authorization: Bearer {token}
```

### 1.4 Logout All Devices
```
POST /auth/logout-all
Authorization: Bearer {token}
```

### 1.5 Get Current User


### 1.6 Refresh Token


### 1.7 Update Profile

## 2. Public Catalog

All endpoints in this section are **public** (no authentication required).

### 2.1 List Products
```
GET /products
```
**Query Parameters:**

| Parameter | Type | Description |
|---|---|---|
| `page` | int | Page number (default: 1) |
| `per_page` | int | Items per page (default: 15, max: 100) |
| `category_slug` | string | Filter by category |
| `brand_slug` | string | Filter by brand |
| `search` | string | Search in name/description |
| `sort` | string | `newest`, `price_asc`, `price_desc`, `popular` |
| `min_price` | int | Minimum price (IDR) |
| `max_price` | int | Maximum price (IDR) |
| `is_bestseller` | bool | Filter bestseller only |

## 3. Cart

**Authentication**: Optional (guest or authenticated)
**Guest Usage**: Include `X-Session-Id: {uuid}` header, or a session UUID will be auto-generated.

### 3.1 Get Cart
```
GET /cart
Authorization: Bearer {token}   # optional
X-Session-Id: {uuid}           # for guest carts
```

**Response 200:**
```json
{
    "success": true,
    "data": {
        "id": "cart_uuid_or_id",
        "items": [
            {
                "id": 1,
                "product": {
                    "id": 1,
                    "name": "Battery Pack 48V",
                    "slug": "battery-pack-48v",

                "qty": 2,
```

## 14. Error Codes

All errors return a consistent JSON structure:

```json
{
    "success": false,
    "message": "Human-readable error message",
    "error": "machine_readable_error_code"
}
```

### HTTP Status Codes

| Status | Meaning |
|---|---|
| 200 | Success |
| 201 | Created |
| 204 | No Content (successful delete) |
| 400 | Bad Request |
| 401 | Unauthenticated |
| 403 | Forbidden |
| 404 | Not Found |
| 422 | Validation Error |
| 429 | Rate Limited |
| 500 | Server Error |

### Error Codes

| Code | HTTP | Description |
|---|---|---|
| `auth_invalid_credentials` | 422 | Wrong email/password |
| `auth_rate_limit` | 429 | Too many failed login attempts (5 attempts/15 min) |
| `auth_email_throttled` | 429 | Email temporarily blocked |
| `auth_ip_throttled` | 429 | IP temporarily blocked |
| `auth_unverified_email` | 403 | Email not verified |

## Notes for Flutter Team

### Token Storage
- Store the Sanctum token securely (e.g., Flutter SecureStorage).
- Include in all authenticated requests:
  ```dart
  headers: {
    'Authorization': 'Bearer $token',
    'Accept': 'application/json',
    'Content-Type': 'application/json',
  }
  ```

### Guest Cart Handling
- For unauthenticated users, generate a UUID and store it locally.
- Send it as `X-Session-Id: {uuid}` header.
- On login, cart items from the guest session will be merged with the user's existing cart.

### FCM Push Notifications
1. Register FCM token after user logs in: `POST /notifications/fcm-token`
2. Unregister on logout: `DELETE /notifications/fcm-token`
3. Handle push notification payloads in Flutter.

### Image URLs
- All image URLs are absolute URLs from the media library.
- Use `thumbnail_url` for lists, full `url` for detail views.
- Lazy-load images in list views.

### Currency Formatting
- All prices are in Indonesian Rupiah (IDR), integers (no decimals).
- Format locally: `Rp ${number.format(0, '.', ',')}`.
